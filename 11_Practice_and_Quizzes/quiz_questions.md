
# Python Quiz Questions and Answers

## Multiple Choice Questions

**1. Which keyword is used to define a function in Python?**

a) function  
b) def  
c) define  
d) fun  

Answer: b) def

**2. Which data type stores multiple values in an ordered collection?**

a) List  
b) Integer  
c) Float  
d) Boolean  

Answer: a) List

**3. Which operator is used for exponentiation?**

a) +  
b) //  
c) **  
d) %  

Answer: c) **

**4. Which loop is used to repeat statements?**

a) if  
b) for  
c) class  
d) return  

Answer: b) for

**5. Which keyword is used to handle exceptions?**

a) catch  
b) error  
c) except  
d) stop  

Answer: c) except

**6. Which method is used to add an element to a list?**

a) add()  
b) append()  
c) insertFile()  
d) push()  

Answer: b) append()

**7. Which symbol is used for comments in Python?**

a) //  
b) <!-- -->  
c) #  
d) **  

Answer: c) #

**8. Which method is automatically called when an object is created?**

a) start()  
b) main()  
c) __init__()  
d) create()  

Answer: c) __init__()

**9. Which file mode is used to append data?**

a) r  
b) w  
c) a  
d) x  

Answer: c) a

**10. Which keyword is used to stop a loop?**

a) stop  
b) break  
c) exit  
d) end  

Answer: b) break
